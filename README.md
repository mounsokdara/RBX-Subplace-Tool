## ROBLOX!!! SUBPLACES TOOOLS!!
**Adds a Subplaces tab to Roblox games pages and a notice when you are viewing a subplace.**

It's bring back ability to join back subplaces server, and your private server or join subplace right on your subplace tabs

You can also share your private server access code to your friend allow them to join your private server

## installation: 

**important for For Android**:
First Install a chromium based broswer that iclude extension 
From my list, i only know these browser that include dev tool and extension:
  - (Kwi Browser)[https://github.com/kiwibrowser/src.next/releases]
  - (Titanium)[https://github.com/jqssun/android-titanium-browser/releases]


**Moving on To extension installation.**

   1 Download my source code
   
   2 Open extension page
   
   3 Turn on dev mode
   
   ** Method 1:**
  - Drag and drop your zip file to the extension page
   And login your roblox account to (roblox.com)[https://roblox.com]
   *Method 2**
   
  - Unzip your extension file
  
  - Then Click on `'Load unpacked'` Select your Unziped extension folder
  - And And login your roblox account to (roblox.com)[https://roblox.com]
   
   Now You should have subplace tabs in your roblox
